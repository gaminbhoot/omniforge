🧱 Tech decisions that need locking before Aug 24

  • Memory backend: SQLite (zero ops, file-backed) vs Redis (ephemeral, better compaction). Call: SQLite for hackathon — fewer moving parts, survives demo restarts.
  • SSE vs WebSocket: SSE for server→UI stream + REST for approvals is simpler than bidirectional WS. Use SSE unless TrueForge SDK forces WS.
  • Sandbox image: python:3.11-slim + pandas/duckdb + curl/kubectl stub. Memory limit 512MB, no host mount, 30s timeout.
  • UI framework: Next.js 14 App Router + Tailwind + shadcn. Already implied in spec; aligns with Vercel deploy story.
  • Package manager: Specify pnpm or bun — lock it before contributors join.
